> # Diploma work proposal and scope

> ## Diploma work title
Development of a route-planning system on a virtual 3D map.

> ## Diploma work overview
AITU3DRPS is a web-based route-planning system intended to help students, staff, and visitors navigate Astana IT University's campus facilities through an interactive virtual 3D environment. The diploma work focuses on making indoor locations easier to understand and helping users find routes between selected points.

> ## Proposal

> ### Problem statement
Traditional static maps and text-based directions can make it difficult to understand campus layouts, identify entrances, and locate lecture halls or other facilities. This can be particularly challenging for first-year students during onboarding. AITU has three campuses Korkem, EXPO, and the Main Campus which makes finding the correct location more complicated.

> ### Target users
The primary target users are first-year AITU students. Other students, staff, and visitors who need to find locations within the covered campus environment are secondary users.

> ### Diploma work goal
Develop a functional web application that allows users to explore a virtual 3D campus map, select a starting point and destination, and view a calculated route between them.

> ## Scope

> ### Included
A web application built with React, TypeScript, Vite, Three.js, and React Three Fiber. 3D assets modeled or prepared in Blender. A virtual map of the selected AITU campus area, beginning with the existing Main Campus indoor demo. Selectable locations such as rooms, lecture halls, entrances, and facilities represented in the map data. Route calculation between selected locations. 3D route visualization and basic route information. Functional testing and evaluation of the prototype.

> ### Excluded
Mapping the user's real-world GPS location to a position on the virtual 3D map.
Live GPS tracking or turn-by-turn outdoor navigation. A production-ready map of every AITU campus unless the diploma work schedule and available data permit expansion. User accounts, administrative dashboards, or a backend database unless they become necessary for the core functionality.
